## Опис проєкту

Ця лабораторна робота присвячена створенню віконних додатків мовою Java з використанням бібліотеки **Swing**. Метою є розробка інтерактивного калькулятора для розв'язання прямої та обернених задач за законом Ома.

**Вимоги до середовища:** Для компіляції та успішного запуску коду необхідний встановлений **JDK (Java Development Kit)**.

**Загальна реалізація:** Проєкт міститься у пакеті `lab9`. Головний клас `OhmLawLab` успадковує `JFrame` і містить логіку ініціалізації вікна, розміщення елементів керування та обробки подій користувача.

## Реалізовані завдання

* **Створення графічного інтерфейсу:** * Вікно налаштоване з використанням абсолютного позиціювання (`setLayout(null)`).
  * Додано текстові мітки (`JLabel`) та поля для вводу даних (`JTextField`) для трьох фізичних величин: Опір (R), Напруга (U) та Сила струму (I).
  * Розміщено кнопки (`JButton`) «Обчислити» та «Очистити».
* **Обчислення за законом Ома:**
  * Реалізовано алгоритм визначення того, які саме дані ввів користувач, для автоматичного вибору потрібної формули:
    * `I = U / R`
    * `U = I * R`
    * `R = U / I`
* **Реалізація додаткового завдання (Динамічне блокування полів):**
  * Використано інтерфейс `DocumentListener` для відслідковування змін у текстових полях у реальному часі.
  * Якщо користувач заповнює будь-які два поля, третє автоматично блокується (`setEditable(false)`), запобігаючи некоректному вводу.
* **Обробка виняткових ситуацій та валідація:**
  * Додано перевірки на ділення на нуль (нульовий опір або нульова сила струму) із виведенням відповідних попереджень через `JOptionPane`.
  * Реалізовано перехоплення винятку `NumberFormatException` на випадок, якщо користувач вводить некоректні символи замість чисел.
* **Очищення форми:** Кнопка «Очистити» скидає всі текстові поля та розблоковує їх для нових розрахунків.

2. Переконайтеся, що у вас встановлено JDK.
