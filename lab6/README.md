## Опис проєкту

Ця лабораторна робота присвячена вивченню принципів об'єктно-орієнтованого програмування в мові Java, зокрема створенню класів, використанню конструкторів, перевантаженню методів, а також реалізації ієрархії через успадкування та абстрактні класи.

**Вимоги до середовища:** Для компіляції та успішного запуску коду необхідний встановлений **JDK (Java Development Kit)**.

**Загальна реалізація:** Проєкт побудований за модульним принципом. Усі класи організовані в межах пакета `lab6`. Точкою входу є головний клас `Lab6Runner`, який послідовно запускає методи для демонстрації кожного із завдань.

## Реалізовані завдання

1. **Завдання 1 (Клас Person):**
   * Створено клас `Person` із полями `fullName` та `age`.
   * Реалізовано два конструктори (з параметрами та без), а також методи `move()` і `talk()` для імітації поведінки об'єктів.

2. **Завдання 2 (Клас Phone):**
   * Створено клас `Phone` з полями `number`, `model` та `weight`.
   * Продемонстровано роботу перевантажених конструкторів та методу `receiveCall` (з одним і двома параметрами).
   * Реалізовано метод `sendMessage` з аргументами змінної довжини (varargs) для масової розсилки повідомлень на декілька номерів.

3. **Завдання 3 (Ієрархія Shape):**
   * Побудовано ієрархію геометричних фігур на основі базового класу `Shape`.
   * Реалізовано класи-спадкоємці: `Pyramid` (безпосередньо наслідує `Shape`), а також `Cylinder` та `Ball` (наслідують проміжний клас `SolidOfRevolution`), з інкапсульованим розрахунком їхніх об'ємів.

4. **Завдання 4 (Абстрактний клас Car):**
   * Створено абстрактний клас `Car` з реалізованим методом `gas()` та абстрактним методом `brake()`.
   * Побудовано похідні класи `Sedan` та `Truck`, кожен з яких по-своєму перевизначає логіку гальмування.

5. **Завдання 5 та 6 (Індивідуальний варіант - Банківський рахунок):**
   * Згідно з індивідуальним завданням розроблено базовий клас `BankAccount` (поля: ім’я, номер рахунку, сальдо) із методами для поповнення та зняття коштів (з урахуванням перевірок балансу).
   * На його основі створено клас-спадкоємець `CreditAccount`, який розширює функціонал батька: додає поля кредитного ліміту та відсоткової ставки, а також перевизначає метод `displayData()` для виведення розширеної інформації.

## Як запустити локально

1. Відкрийте термінал та перейдіть у кореневу папку проєкту (де знаходиться папка `lab6`).
2. Переконайтеся, що у вас встановлено JDK (можна перевірити командою `javac -version`).
3. Скомпілюйте одразу всі класи лабораторної роботи:
   
   `javac lab6/*.java`

4. Запустіть головний файл програми:

   `java lab6.Lab6Runner`
