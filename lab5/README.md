## Опис проєкту

Ця лабораторна робота присвячена опануванню принципів об’єктно-орієнтованого програмування, зокрема створенню власних класів, методів та реалізації механізмів обробки виняткових ситуацій (Exceptions). Програма демонструє взаємодію між класами, передачу параметрів у методи, повернення значень та безпечне зчитування даних від користувача через консоль.

**Вимоги до середовища:** Для компіляції та успішного запуску коду необхідний встановлений **JDK (Java Development Kit)**.

**Загальна реалізація:** Проєкт побудований за модульним принципом у межах пакета `lab5`. Точкою входу є головний клас `Lab5_Main`, який організовує логіку програми, викликаючи методи допоміжних класів для кожного окремого завдання. Важливою особливістю є використання блоків `try-catch` для обробки помилок введення та логічних винятків.

## Реалізовані завдання

1. **Завдання 1 (Обчислення площі):** * Використовується клас `Lab5_RectArea` для розрахунку площі прямокутника. 
   * Реалізовано перевірку вхідних параметрів: якщо користувач вводить від’ємні значення сторін, програма генерує та обробляє `IllegalArgumentException`.

2. **Завдання 2 (Аналіз чисел):** * Клас `Lab5_MinOfThree` містить метод `findMin`, який за допомогою стандартної бібліотеки `Math` знаходить найменше число серед трьох введених значень.

3. **Завдання 3 (Робота з масивами та форматування):** * Реалізовано динамічне створення масиву з перевіркою коректності його розміру.
   * Використовується спеціалізований клас `Lab5_PrintArray`, який перетворює вміст масиву у відформатований рядок для зручного виведення на екран, обробляючи випадки порожніх масивів.

4. **Завдання 4 (Пошук максимуму):** * Клас `Lab5_MaxInArray` реалізує алгоритм ітераційного пошуку найбільшого елемента в масиві.
   * Передбачено захист від помилок у разі передачі в метод неініціалізованого або порожнього масиву.
