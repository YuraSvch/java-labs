## Опис проєкту

[cite_start]Мета роботи: набуття навичок опрацювання основних класів і методів роботи з потоками та файлами.
Ця лабораторна робота демонструє базові принципи взаємодії з файловою системою в мові Java через використання класів для роботи з файлами та символьних потоків введення-виведення.

**Вимоги до середовища:** Для компіляції та успішного запуску коду необхідний встановлений **JDK (Java Development Kit)**.

**Загальна реалізація:** Проєкт міститься у пакеті `lab8` і складається з одного головного класу `Main`. Програма отримує вхідні параметри через командний рядок, після чого генерує числові дані, зберігає їх у текстовий файл на диску та зчитує назад для демонстрації результату.

## Реалізовані завдання

[cite_start]Для виконання завдання використано потоки реалізовані з допомогою класів `FileWriter` та `FileReader`.
* [cite_start]**Генерація та запис:** Реалізовано програму, що записує в файл (типу txt) послідовність випадкових чисел у діапазоні, що вказаний за допомогою параметрів командного рядка.
* [cite_start]**Передача параметрів:** Ім’я файлу вказується також в командному рядку. Загалом програма приймає три аргументи: ім'я файлу, початкову та кінцеву межі діапазону.
* [cite_start]**Перевірка та створення:** У програмі передбачено перевірку існування файлу з заданим ім'ям, в разі його відсутності попередньо перед записом в файл, виконується його створення. 
* [cite_start]**Алгоритм рандомізації:** Для генерування випадкового числа в межах [b1,b2], використано формулу `new Random().nextInt(b2-b1+1)+b1`. Загалом генерується 10 чисел.
* [cite_start]**Зчитування даних:** Програма здатна прочитати інформацію з файлу, створеного у попередньому завданні, та вивести її на консоль. Читання здійснюється посимвольно до досягнення кінця файлу.
* **Обробка винятків:** Додано блоки `try-catch` для коректної обробки помилок парсингу числових меж (`NumberFormatException`) та помилок введення/виведення (`IOException`).
